# CIS 5660 Lab 06 Procedural Buildings

A small two-storey office with an L-shaped footprint and an open courtyard. It has terracotta walls, blue windows, and a simple entrance canopy.

![Building](images/building_hero.png)

The floor dimensions are adjustable. The walls are split into bays, and window, storefront, and door modules are placed with Copy to Points.

For the advanced part, I added random window variants (27:07) and floor borders (35:22). The random seed controls which windows have blinds.

![Entrance](images/building_entrance.png)

Open `lab06.hipnc` to inspect the generator. Both HDA definitions are embedded in the file.
